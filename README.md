# ai 军师 jev 改进版

一个用于理解聊天内容、整理可能意图和起草参考回复的 macOS 小工具。

基于 [Jev 聊天助手](https://github.com/jev-chat/jev-chat-jarvis-mac) 二次开发；这是独立改进版，与原作者及微信、抖音没有官方关联。

## 支持的平台

目前安装包仅支持 **Apple 芯片（M1/M2/M3/M4 等）Mac，macOS 13 或更高版本**。Windows、Linux、Intel Mac 尚未适配。界面、文字识别、窗口跟随使用 macOS 原生接口。

## 功能

- **微信**：读取当前可见的聊天文字，逐条展示可能意图、沟通紧张度、行动建议和参考回复。每条消息结合之前已读取的上下文分析，不会读取整个账号的历史记录。
- **开始 / 暂停**：默认暂停；开始后持续检查新消息，暂停后不再发起新分析。已经发出的网络请求可能仍会结束，结果不再应用。
- **自适应窗口**：拖动边缘改变宽高，卡片自动调整列数；保留窗口大小，跟随微信窗口移动。
- **抖音私信**：框选屏幕、导入截图或粘贴文字，校对发言人后分析，生成三种语气的参考回复。网页版和客户端均可作为截图来源；这是手动分析流程。
- **回复分区**：绿色区域显示可复制的回复；详情可以展开。逐条模式和抖音流程由用户自行复制、决定是否发送。

百分比是模型在选项之间的估计，不是经过校准的心理测量，也不能证明对方的真实想法。无法确认发言人时会明确提示。

## 下载和启动

到 [Releases](https://github.com/Vles0123/ai-junshi-jev/releases) 下载 `ai-junshi-jev-v0.3.0-macos-arm64.zip`，解压后把应用放进“应用程序”，再打开。

首次启动需要联网安装 Python 和依赖，可能需要几分钟。应用主要通过菜单栏运行；在菜单栏找到 **VC**，可打开面板、模型设置或“抖音私信…”。

安装包采用临时本地签名，**没有 Apple Developer ID 签名和公证**。macOS 可能阻止首次启动。确认来源后可使用系统“隐私与安全性”中的打开选项；也可以按下方步骤从源码运行。不要关闭系统的全局安全保护。

### 配置自己的模型

公版没有内置密钥、共享额度或聊天数据。

1. 打开“设置” → **智谱 GLM**。
2. 填写自己的 API Key、服务地址和账号可用的模型名称。默认服务地址为 `https://open.bigmodel.cn/api/paas/v4`，预填模型 `glm-5.3`；模型是否可用取决于你的账号。
3. 点击“测试连接”，保存并重启。默认情况下同一组智谱配置用于判断和生成回复。
4. 如需独立的回复模型，可配置“生成 · OpenAI”或“生成 · Anthropic”。生成服务优先级为 OpenAI、Anthropic、智谱。

请自行确认供应商额度和允许的用途；网页会员、Coding Plan 与通用 API 权益可能不同。公版不提供或保证任何订阅额度的通用聊天用途。

保留了上游 Jev / 离线判断适配代码，默认不下载离线模型。新版微信逐条卡片使用智谱判断和辅助功能读取；切换旧判断后端并不保证相同界面体验。

### 微信

按系统提示给本应用开启“辅助功能”；使用截图/OCR 时还需“屏幕录制”权限。授权后完整退出并重新打开应用。

打开有文字消息的微信聊天窗口，点击面板“开始”。默认最多取 20 条上下文；当前可见消息不等于完整聊天记录。暂停后仍可保留面板，下次点击开始继续。

### 抖音

菜单栏 **VC → 抖音私信…**，选择“框选私信区”“导入截图”或“粘贴文字”。

每条消息以 `我：` 或 `对方：` 开头。删除时间、昵称、界面按钮和无法确认的 OCR 内容，确保最后一条是要回复的对方消息，勾选“文字与发言人已校对”，再点“分析对话”。结果和三条绿色参考回复显示在下方。

## 隐私与本地数据

- 发布文件仅包含代码、依赖清单、图标、文档和测试；不包含作者的 Key、账户配置、聊天记录、截图、日志或模型缓存。
- **API 分析会将消息文字、选中的上下文和填写的关系背景发给所配置的模型服务商**；文字识别在本机完成。使用前请确认适合分享这些内容。
- 默认关闭持久聊天历史。用户主动开启历史后，相关数据会保存在本机。
- 为兼容旧版本，本地目录继续使用 `vles-chat`：配置在 `~/.config/vles-chat/env`，运行环境在 `~/Library/Application Support/vles-chat/`，启动日志在 `~/Library/Logs/vles-chat.log`。
- 配置文件以仅当前用户可读写的权限创建；密钥是本地配置文件中的明文，请勿上传该文件或将私人运行目录打包。
- `env.example` 仅提供空密钥模板；应用不会覆盖已有配置。

## 从源码运行

需要 Apple 芯片 Mac、Python 3.12 和 [uv](https://docs.astral.sh/uv/)。可直接克隆完整仓库：

```sh
git clone https://github.com/Vles0123/ai-junshi-jev.git
cd ai-junshi-jev
```

然后在项目目录执行：

```sh
uv sync --frozen --python 3.12
uv run python src/vles_bootstrap.py
uv run python src/hud.py
```

也可以先执行 `chmod +x start.command`，再双击 `start.command`。命令行运行时，系统权限可能归属终端/Python；正式使用建议构建应用。

### 构建安装包

安装 Xcode Command Line Tools 后执行：

```sh
uv run python packaging/build_app.py --output dist
```

生成 `dist/ai 军师 jev 改进版.app`。构建不会复制个人配置，也不会内置模型权重或密钥。首次运行仍需下载依赖。

### 测试

```sh
uv run python -m unittest discover -s tests
```

本次发布的完整测试结果及已知遗留问题见 [VALIDATION.md](VALIDATION.md)。测试使用合成对话；不得提交真实聊天作为测试样本。

## 已知限制

微信版本、窗口布局和系统权限会影响识别。截图 OCR 可能漏字或识别错发言人；抖音必须校对。API 延迟与网络、模型有关。没有内容或权限失败时，请查看界面提示，不要把空结果当作分析完成。

升级临时签名的应用后，macOS 可能要求重新授权。遇到启动问题先查看本地日志，分享日志前移除私人信息。
